## Sending safely

The official API lowers your risk, but WhatsApp still restricts numbers that spam. To keep your number healthy:

- Message only people who agreed to hear from you
- Use approved templates for the first message on the official API
- Keep the daily caps and message gaps on, and grow volume slowly on a new number
- Give people an easy way to opt out
